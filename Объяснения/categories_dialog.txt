==========================================================================
 categories_dialog.py — окно управления категориями
==========================================================================

ЗАЧЕМ НУЖЕН ФАЙЛ
----------------
Форма окна — ui/categories_dialog.ui (Qt Designer). Здесь поведение:
список категорий с цветными кружками и четыре действия — добавить,
изменить цвет, переименовать, удалить.

В отличие от окна задачи, здесь изменения пишутся в базу СРАЗУ: каждая
кнопка выполняет одно законченное действие, и подтверждать его ещё
отдельной кнопкой "Сохранить" было бы лишним шагом.

В этом окне используются сразу три стандартных диалога Qt:
QColorDialog (выбор цвета), QInputDialog (ввод названия),
QMessageBox (предупреждения и вопросы — через dialogs.py).

ФУНКЦИЯ make_color_icon(color_name) -> QIcon
--------------------------------------------
Рисует цветной кружок и возвращает его как значок для пункта списка.
Цвет выбирает пользователь (любой из 16 миллионов), поэтому заранее
картинок не наготовишь — рисуем кодом.

  pixmap = QPixmap(14, 14)
      QPixmap — картинка в памяти, пока "пустой холст" 14x14.
  pixmap.fill(Qt.transparent)
      Новый QPixmap заполнен случайным мусором — делаем фон прозрачным,
      чтобы вокруг кружка не было цветных квадратных углов.
  painter = QPainter(pixmap)
      QPainter — инструмент рисования, "кисть", направленная на холст.
  painter.setRenderHint(QPainter.Antialiasing) — сглаживание краёв.
  painter.setBrush(QColor(color_name)) — заливка цветом категории.
  painter.setPen(Qt.NoPen) — без обводки.
  painter.drawEllipse(0, 0, 14, 14) — круг во весь холст.
  painter.end()
      Обязательно завершить рисование: пока QPainter активен, QPixmap
      "занят", и использовать его как иконку нельзя.
  return QIcon(pixmap) — превращаем картинку в иконку.


КЛАСС CategoriesDialog(QDialog)
-------------------------------
КОНСТРУКТОР __init__(self, database, parent=None)
  self._db = database
  uic.loadUi(CATEGORIES_DIALOG_UI, self) — виджеты формы становятся
      атрибутами (self.categoriesListWidget, self.addCategoryButton...).
  categoriesListWidget.setIconSize(14x14) — размер значков в списке,
      иначе Qt растянул бы кружки до стандартного размера.
  Иконка "корзина" на кнопке удаления и иконка окна.
  _connect_signals(), _refresh_categories_list().


_connect_signals()
------------------
  addCategoryButton    -> _add_category
  changeColorButton    -> _change_color
  renameCategoryButton -> _rename_category
  deleteCategoryButton -> _delete_category

  closeButton.clicked -> self.accept
      Именно accept(), а не reject(): закрытие — не "отмена", изменения
      уже в базе. (Главное окно в любом случае перечитывает категории
      после закрытия.)

  categoriesListWidget.itemDoubleClicked -> _change_color
      Двойной клик по категории (МЫШЬ) сразу открывает выбор цвета —
      самое частое действие в этом окне. Сигнал itemDoubleClicked
      передаёт пункт, по которому щёлкнули, а _change_color параметров
      не принимает. Это не ошибка: если у слота меньше параметров, чем
      у сигнала, PyQt просто отбрасывает лишние аргументы. Выделенный
      пункт метод берёт сам через currentItem() — двойной клик его как
      раз и выделил.


_refresh_categories_list()
--------------------------
  clear() — очистить список.
  Для каждой категории из базы:
    item = QListWidgetItem(название)
    item.setIcon(make_color_icon(цвет)) — кружок слева от названия.
    item.setData(Qt.UserRole, id) — id в скрытых данных пункта: по нему
        работают кнопки переименования, цвета и удаления.
    addItem(item).


_selected_category()
--------------------
Возвращает строку выделенной категории из базы или None.
  currentItem() — выделенный пункт (None, если ничего не выделено).
  item.data(Qt.UserRole) — достаём id.
  Затем ищем категорию с этим id среди get_categories() и возвращаем
  её (нужны актуальные название и цвет).
Если ничего не выделено — кнопки просто ничего не делают (return).


_add_category() — ДОБАВЛЕНИЕ
----------------------------
  1) name = _ask_category_name(...) — окно ввода названия. None или
     пустая строка — пользователь отказался, выходим.
  2) color = _ask_color(серый_по_умолчанию) — окно выбора цвета. None —
     отказ, выходим.
  3) try:
         self._db.add_category(name, color)
     except sqlite3.IntegrityError:
         self._warn_name_taken(name); return
     ОБРАБОТКА ИСКЛЮЧЕНИЯ. Столбец name в базе объявлен UNIQUE, поэтому
     сама база не даст создать вторую категорию с тем же названием и
     выбросит IntegrityError ("нарушение целостности"). Мы её ловим и
     показываем понятное предупреждение вместо падения программы.
     Проверку уникальности делает база, а не наш код — это надёжнее.
  4) Перерисовать список.


_rename_category() — ПЕРЕИМЕНОВАНИЕ
-----------------------------------
  Берём выделенную категорию. Окно ввода открывается с текущим
  названием (третий параметр). Если ввели пустое или то же самое —
  ничего не делаем. Иначе rename_category в try/except — та же защита
  от занятого названия.


_change_color() — СМЕНА ЦВЕТА
-----------------------------
  Выделенная категория -> _ask_color(её текущий цвет) -> если не
  отменили, set_category_color и перерисовка.


_delete_category() — УДАЛЕНИЕ С ЗАПРЕТОМ
----------------------------------------
  1) Если category_has_tasks(id) — show_warning "В категории «...» есть
     задачи. Сначала перенесите их..." и выход. ТРЕБОВАНИЕ ТЗ:
     категорию с задачами удалить нельзя, приложение предупреждает.
  2) ask_yes_no "Удалить категорию «...»?" — "Нет" -> выход.
  3) delete_category и перерисовка.


_ask_category_name(header, label, current_name="") — QInputDialog
-----------------------------------------------------------------
Короткий готовый вызов QInputDialog.getText(...) подписывает кнопки
по-английски ("OK", "Cancel"). Поэтому диалог создаётся как объект и
настраивается вручную:
  dialog = QInputDialog(self)
  setWindowTitle — заголовок, setLabelText — подпись над полем,
  setTextValue — начальный текст (при переименовании — старое имя),
  setOkButtonText("ОК"), setCancelButtonText("Отмена") — русские
  кнопки.
  if dialog.exec_() != QDialog.Accepted: return None — нажали "Отмена".
  return dialog.textValue().strip() — введённый текст без пробелов по
  краям.


_ask_color(current_color) — QColorDialog
----------------------------------------
  color = QColorDialog.getColor(QColor(current_color), self, заголовок)
      Стандартное окно выбора цвета (палитра, пипетка, ввод HEX).
      Первый аргумент — начальный цвет, чтобы окно открывалось на
      текущем цвете категории, а не на белом.
  if not color.isValid(): return None
      При нажатии "Отмена" getColor возвращает НЕДЕЙСТВИТЕЛЬНЫЙ цвет —
      так мы узнаём об отказе.
  return color.name() — строка "#rrggbb", в таком виде цвет хранится в
      базе и подставляется в стили карточек.


_warn_name_taken(name)
----------------------
Общий для добавления и переименования показ предупреждения "Категория
«...» уже есть в списке." — вынесен, чтобы не повторять код дважды.

ВОЗМОЖНЫЕ ВОПРОСЫ НА ЗАЩИТЕ
---------------------------
В: Как не даёшь создать две одинаковые категории?
О: В базе name UNIQUE. При повторе SQLite бросает IntegrityError, я
   ловлю её в try/except и показываю предупреждение.

В: Почему нельзя удалить категорию с задачами?
О: По ТЗ. Перед удалением category_has_tasks считает задачи
   (SELECT COUNT(*)), и если они есть — показывается предупреждение.

В: Откуда цветные кружки?
О: Рисуются кодом: QPixmap как холст + QPainter рисует круг цветом
   категории, результат становится QIcon.

В: Как узнаёшь, что в QColorDialog нажали "Отмена"?
О: Возвращается недействительный цвет, color.isValid() == False.
