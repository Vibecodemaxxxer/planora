==========================================================================
 task_calendar.py — календарь с собственной отрисовкой дней
==========================================================================

ЗАЧЕМ НУЖЕН ФАЙЛ
----------------
Обычный QCalendarWidget плохо поддаётся оформлению. Внутри он собран из
таблицы и служебных кнопок, цвета дней берёт из палитры, и файл стилей
QSS до клеток дней почти не достаёт. Скруглить выделение выбранного дня
или нарисовать точку под днём с дедлайном через QSS нельзя вообще.

Решение — свой класс-наследник TaskCalendar, в котором переопределён
метод paintCell(). Qt вызывает этот метод для КАЖДОЙ клетки дня,
передавая "кисть" (QPainter), прямоугольник клетки и дату. Что
нарисовать в этом прямоугольнике — решаем мы.


ЧТО ТАКОЕ ПЕРЕОПРЕДЕЛЕНИЕ МЕТОДА
--------------------------------
TaskCalendar наследуется от QCalendarWidget, то есть умеет всё то же
самое: листать месяцы, выбирать день, посылать сигнал selectionChanged.
Но у него есть свой метод paintCell с тем же именем, что у родителя.
Когда Qt хочет нарисовать клетку, он вызывает paintCell у объекта — и
вызывается наша версия, а не родительская. Остальное поведение
календаря не меняется.


КАК КЛАСС ПОПАДАЕТ НА ФОРМУ ("ПОВЫШЕНИЕ" / PROMOTION)
-----------------------------------------------------
На форме main_window.ui в Qt Designer стоит обычный QCalendarWidget.
Но он "повышен" (promoted) до класса TaskCalendar: в Designer — правый
клик по виджету -> "Преобразовать в..." -> указать имя класса
TaskCalendar и заголовочный файл task_calendar.

В XML формы это выглядит как блок <customwidgets>. uic.loadUi(), читая
форму, видит его, сам делает import task_calendar и создаёт вместо
QCalendarWidget наш TaskCalendar. Так и форма остаётся в Designer, и
отрисовка — наша.


ИМПОРТЫ
-------
  QDate — дата в Qt (сравнение, день недели, текущая дата).
  QRectF — прямоугольник с дробными координатами.
  Qt — константы (выравнивание, "без обводки").
  QColor — цвет. QPainter — инструмент рисования.
  QCalendarWidget — родительский класс.
  Константы CALENDAR_* — цвета и размеры из constants.py.


КОНСТРУКТОР __init__(self, parent=None)
---------------------------------------
  super().__init__(parent)
      Сначала вызываем конструктор родителя — чтобы QCalendarWidget
      создал всё своё внутреннее устройство. Без этой строки объект был
      бы "недостроен" и Qt упал бы.

  self._deadline_days = {}
      Словарь {QDate: True/False}. Ключ — день с дедлайнами, значение —
      есть ли среди задач этого дня просроченная. Календарь САМ в базу
      не ходит: данные ему передаёт главное окно. Так класс не зависит
      от базы данных.

  self.setVerticalHeaderFormat(QCalendarWidget.NoVerticalHeader)
      Убираем колонку с номерами недель — это лишний шум.

  self.setGridVisible(False)
      Не рисуем линии сетки: дни разделяют отступы.


МЕТОД set_deadline_days(deadline_days)
--------------------------------------
Главное окно передаёт сюда словарь дней с дедлайнами.
  self.update() — просит Qt перерисовать виджет. Без этого вызова точки
  обновились бы только при следующей случайной перерисовке (например,
  при наведении мыши). update() не рисует сразу, а ставит перерисовку
  в очередь — Qt объединит несколько запросов в одну.


МЕТОД paintCell(painter, rect, date) — главный
----------------------------------------------
Вызывается Qt для каждого дня на экране (≈42 раза за перерисовку).

  painter.save() ... painter.restore()
      QPainter один на весь календарь. Если мы поменяем ему цвет или
      шрифт и не вернём обратно, эти настройки "утекут" в отрисовку
      соседних клеток. save() запоминает состояние кисти, restore()
      возвращает его.

  painter.setRenderHint(QPainter.Antialiasing)
      Сглаживание — без него у скруглённых углов и кружков видны
      "ступеньки".

  Три признака дня:
      is_selected = date == self.selectedDate()   — выбранный день
      is_today = date == QDate.currentDate()      — сегодняшний
      is_current_month = date.month() == self.monthShown()
          календарь показывает и хвосты соседних месяцев, их рисуем
          бледно.

  Порядок рисования — "как у художника", от заднего плана к переднему:
      1) подложка (_paint_background);
      2) число (_paint_day_number);
      3) точка-отметка (_paint_deadline_dot), если день есть в словаре
         и он НЕ выбран — у выбранного дня тёмная подложка, точка на
         ней не видна, да и задачи этого дня и так показаны справа.


МЕТОД _paint_background(painter, rect, is_selected, is_today)
-------------------------------------------------------------
@staticmethod — метод не использует self (данные объекта), поэтому
объявлен статическим. Это подсказка читателю: "этот метод зависит
только от своих аргументов".

  Если день не выбран и не сегодняшний — подложки нет, return.
  Цвет: тёмный (#18181b) у выбранного, светло-серый у сегодняшнего.

  cell = QRectF(rect).adjusted(m, m, -m, -m)
      Прямоугольник клетки, уменьшенный на отступ со всех сторон.
      adjusted(dx1, dy1, dx2, dy2) сдвигает левый-верхний угол на
      (+m, +m), а правый-нижний на (-m, -m).
      QRectF (дробные координаты) — со сглаживанием углы аккуратнее.

  painter.setPen(Qt.NoPen)       — без обводки ("перо" — контур);
  painter.setBrush(QColor(color))— заливка ("кисть" — заполнение);
  painter.drawRoundedRect(cell, радиус, радиус) — скруглённый
      прямоугольник.


МЕТОД _paint_day_number(...)
----------------------------
Выбор цвета числа:
  - выбранный день — белым (по тёмному фону);
  - день соседнего месяца — бледно-серым;
  - выходной (dayOfWeek() 6 или 7 = суббота, воскресенье) — светлее;
  - обычный день — тёмно-серым.

  font = painter.font(); font.setBold(...); painter.setFont(font)
      Жирный шрифт у выбранного дня и у дней с задачами — заметно даже
      без цвета.

  painter.drawText(rect.adjusted(0, -CALENDAR_DOT_SIZE, 0, 0),
                   Qt.AlignCenter, str(date.day()))
      Число рисуется по центру клетки, но клетка сдвинута вверх на
      размер точки — чтобы под числом осталось место для точки.


МЕТОД _paint_deadline_dot(painter, rect, has_overdue)
-----------------------------------------------------
  Цвет: красный, если среди задач дня есть просроченная, иначе тёмный.
  dot_x — центр клетки по горизонтали минус половина точки;
  dot_y — ближе к низу клетки.
  painter.drawEllipse(QRectF(x, y, размер, размер)) — круг
  (эллипс в квадрате = круг).


СВЯЗЬ С ОСТАЛЬНЫМ КОДОМ
-----------------------
main_window.py, метод _mark_calendar_deadlines, собирает словарь дней
из базы и вызывает self.calendarWidget.set_deadline_days(...).
Цвет строки названий дней недели (Пн, Вт...) задаётся в
main_window.py (_prepare_calendar) — её Qt рисует сам, не через
paintCell.


ВОЗМОЖНЫЕ ВОПРОСЫ НА ЗАЩИТЕ
---------------------------
В: Почему не оформил календарь через QSS?
О: QSS не достаёт до клеток дней QCalendarWidget, а скруглённое
   выделение и точку под днём через стили сделать невозможно.

В: Кто вызывает paintCell?
О: Сам Qt, когда календарю нужно перерисоваться. Я только определяю,
   что рисовать.

В: Зачем save()/restore()?
О: Чтобы настройки кисти одной клетки не повлияли на другие.

В: Как календарь оказался на форме, если он — твой класс?
О: Через "повышение" виджета в Qt Designer; uic.loadUi подставляет
   мой класс вместо стандартного.
