==========================================================================
 dialogs.py — окна сообщений с русскими кнопками
==========================================================================

ЗАЧЕМ НУЖЕН ФАЙЛ
----------------
В Qt есть готовые короткие вызовы стандартных окон сообщений:
    QMessageBox.warning(self, "Заголовок", "Текст")
    QMessageBox.question(self, "Заголовок", "Удалить?")
Они удобны, но у них одна проблема: надписи на кнопках задаёт сама
библиотека, и они АНГЛИЙСКИЕ — "OK", "Yes", "No". Поменять их в этих
вызовах нельзя.

Чтобы кнопки были русскими, окно приходится собирать вручную: создать
объект QMessageBox, настроить его и самостоятельно добавить кнопки со
своим текстом.

Такие окна нужны в трёх местах (главное окно, окно задачи, окно
категорий). Чтобы не копировать один и тот же десяток строк трижды,
они вынесены сюда в две функции:
  show_warning — предупреждение с кнопкой "ОК";
  ask_yes_no   — вопрос с кнопками "Да" / "Нет".

Это закрывает критерий "использование стандартных диалогов"
(QMessageBox — стандартный диалог Qt).

Почему функции, а не класс: у них нет своего состояния, которое нужно
хранить между вызовами. Простая функция здесь честнее и короче.


ИМПОРТЫ
-------
  from PyQt5.QtWidgets import QMessageBox — стандартное окно сообщения.
  from constants import BUTTON_NO, BUTTON_OK, BUTTON_YES — тексты
  "Нет", "ОК", "Да".


ФУНКЦИЯ show_warning(parent, header, text)
------------------------------------------
Показывает предупреждение, например "У задачи должно быть название."

  message_box = QMessageBox(parent)
      Создаём окно. parent — окно-родитель: сообщение появится по
      центру над ним, и пока сообщение открыто, с родителем работать
      нельзя (окно модальное).

  message_box.setIcon(QMessageBox.Warning)
      Жёлтый значок с восклицательным знаком.

  message_box.setWindowTitle(header)  — заголовок окна.
  message_box.setText(text)           — текст сообщения.

  message_box.addButton(BUTTON_OK, QMessageBox.AcceptRole)
      Добавляем свою кнопку с текстом "ОК". Второй аргумент — РОЛЬ
      кнопки: он говорит Qt, что эта кнопка значит по смыслу
      ("принять"). От роли зависит поведение — например, какая кнопка
      сработает по Enter/Esc и в каком порядке кнопки встанут.

  message_box.exec_()
      Показывает окно и ЖДЁТ, пока пользователь его не закроет.
      Код после exec_() выполнится только после закрытия. Это и есть
      "модальный" показ.


ФУНКЦИЯ ask_yes_no(parent, header, text) -> bool
------------------------------------------------
Задаёт вопрос вроде "Удалить задачу «Купить хлеб»?" и возвращает
True, если нажали "Да", и False во всех остальных случаях.

  setIcon(QMessageBox.Question) — значок вопроса.

  yes_button = message_box.addButton(BUTTON_YES, QMessageBox.YesRole)
  no_button  = message_box.addButton(BUTTON_NO,  QMessageBox.NoRole)
      addButton возвращает созданную кнопку — сохраняем ссылки на обе,
      чтобы потом понять, какую нажали.

  message_box.setDefaultButton(no_button)
      Кнопка по умолчанию — та, что сработает по Enter. Выбрана "Нет":
      все наши вопросы — про удаление, и случайный Enter не должен
      ничего стирать. Это защита от ошибки пользователя.

  message_box.exec_() — показать и ждать ответа.

  return message_box.clickedButton() is yes_button
      clickedButton() возвращает кнопку, которую нажали. Сравниваем её
      с нашей кнопкой "Да" через  is  (это та же самая кнопка-объект?).
      Если закрыли окно крестиком или нажали "Нет" — результат False,
      то есть ответ считается отрицательным. Безопасное поведение.


КАК ЭТИМ ПОЛЬЗУЮТСЯ ДРУГИЕ ФАЙЛЫ
--------------------------------
  if not ask_yes_no(self, "Удаление задачи", "Удалить задачу?"):
      return          # пользователь передумал
  self._db.delete_task(task_id)

  show_warning(self, "Не хватает данных", "У задачи должно быть название.")


ВОЗМОЖНЫЕ ВОПРОСЫ НА ЗАЩИТЕ
---------------------------
В: Почему не QMessageBox.question(...)?
О: У готового вызова английские кнопки "Yes"/"No". Собрав окно
   вручную, я задаю свои надписи.

В: Что значит "модальное окно"?
О: Пока оно открыто, с родительским окном работать нельзя, а exec_()
   не возвращает управление, пока окно не закроют.

В: Почему по умолчанию "Нет"?
О: Чтобы случайное нажатие Enter не удалило данные.
